# Compass

Профориентация и подбор вузов для школьников Казахстана. Ученик проходит анкету из 7 шагов и получает 5 направлений с прозрачным расчётом, маршрут развития и подбор вузов с Fit Score.

**Сайт:** https://compass-kz.onrender.com

## Что умеет

- **Анкета из 7 шагов:** факты (класс, оценки, страны, бюджет, IELTS/SAT), интересы по модели Холланда (RIASEC, 18 утверждений), ценности по модели Шварца (10 → 5 → дуэли), самооценка 19 навыков, открытые ответы, увлечения, AI-интервью до 7 вопросов.
- **5 направлений из 15** с разбором: вклад каждой оси (интересы 35%, ценности 20%, оценки 20%, навыки 15%, AI-интервью 10%) и зоны риска.
- **Маршрут:** разрыв навыков и план «Прямо сейчас → До поступления → После поступления».
- **24 вуза** (Казахстан, США, Канада, Великобритания, Германия, Швейцария, Нидерланды, Италия, Чехия, Венгрия, Турция, Сингапур, Корея, Япония, Китай) с Fit Score, совпадениями, рисками и чек-листом документов.
- **Аккаунты:** регистрация по email, прогресс сохраняется на сервере и доступен с любого устройства. Можно начать без регистрации и сохранить потом.
- **Ссылка для просмотра:** результат можно показать родителям или ментору (только просмотр, ссылку можно отключить).
- **PDF / печать** результатов, светлая и тёмная тема, мобильная версия.

## Технологии

- Node.js + Express, один файл `server.js`
- PostgreSQL (таблицы с префиксом `compass_`), без базы — JSON-файл для локального запуска
- Фронтенд: один файл `public/index.html`, без сборки
- Пароли — bcrypt, сессии — httpOnly cookie, ограничение попыток входа
- AI (необязательно): Anthropic API через сервер

## Переменные окружения

| Переменная | Зачем |
|---|---|
| `DATABASE_URL` | Строка подключения к Postgres. Без неё данные хранятся в файле и пропадают при перезапуске на Render |
| `ANTHROPIC_API_KEY` | Включает AI-интервью, разбор увлечений и советы по вузам. Без ключа работают готовые вопросы |
| `AI_MODEL` | Модель, по умолчанию `claude-haiku-5-5` |
| `AI_DAILY_LIMIT` | Лимит AI-запросов на ученика в день, по умолчанию 60 |
| `NODE_ENV` | `production` на сервере |

## Запуск локально

```bash
npm install
npm start
# http://localhost:3000
```

## Данные о вузах

Стоимость, требования и рейтинги — ориентир (QS World University Rankings, примерные значения). Перед подачей документов всё нужно сверять с официальным сайтом вуза. Данные лежат в `public/index.html`, массив `UNIS`.
